# Active learning for nonadiabatic molecular dynamics 

Active delta learning for TSH as implemented in open-source MLatom, version >=3.22, and reported in:

- Mikołaj Martyka, Joanna Jankowska*, Pavlo O. Dral*. Active Delta-Learning for Surface Hopping: Efficient Fitting of Potential Energy Surfaces. 2026. Preprint on ChemRxiv: https://doi.org/10.26434/chemrxiv.15002308/v1 (2026.04.22).

See a [dedicated MLatom tutorial](http://mlatom.com/docs/tutorial_tsh_adl.html).

Content:

- The ML models referenced in the paper, as well as the necessary code to run fulvene namd with delta models is available in this repository.
- Training data for all ML models is available at the following DOI: https://doi.org/10.6084/m9.figshare.32008086.
